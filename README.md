# Excel-Dashboard-1
Walmart Dashboard

Walmart Sales Dashboard – Excel

This project is an interactive Walmart Sales Dashboard developed in Microsoft Excel to analyze sales performance, profitability, customer distribution, and order trends across different markets, regions, segments, and categories.

Key Features
KPI Cards: Total Sales, Total Profit, Total Customers, and Profit Margin.
Customer Count by Region: Compares the number of customers across different regions.
Monthly Sales Trend by Segment: Tracks monthly sales performance across Furniture, Office Supplies, and Technology.
Order Distribution by Segment: Shows the percentage contribution of Consumer, Corporate, and Home Office segments.
Profit by Market: Compares profitability across different markets.
Interactive Slicers: Added Segment and Market filters to dynamically analyze the dashboard based on selected criteria.
Pivot Tables & Pivot Charts: Used for data aggregation, analysis, and visualization.
Dashboard Design: Created a user-friendly layout to present important business insights in a clear and concise manner.
Tools Used

Microsoft Excel | Pivot Tables | Pivot Charts | Slicers | Excel Formulas | Data Visualization

The dashboard helps users quickly understand where sales and profits are coming from, how sales change over time, and which markets, regions, and customer segments perform best, supporting data-driven business decisions.
